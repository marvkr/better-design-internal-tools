# Blind comparison rubric

Reviewers receive shuffled screenshots and working URLs without repository,
tool, or variant labels. Score each category from 1 to 5.

| Category | What to assess |
| --- | --- |
| Task clarity | The primary job and next action are obvious within 15 seconds. |
| Information hierarchy | The screen has one dominant task and restrained supporting detail. |
| Interaction quality | Forms, progress, review, completion, keyboard use, and mobile use work. |
| Visual consistency | Type, color, spacing, radius, depth, and icons form a coherent system. |
| Accessibility | Labels, focus, landmarks, contrast, status, and error feedback are usable. |
| Product credibility | The interface feels plausible enough for a real internal team. |

Record the category total, preferred variant, confidence from 1 to 5, and one
sentence explaining the preference. Keep automated failures separate from
human preference scores.
